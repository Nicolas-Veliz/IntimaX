## 🏨 Sistema de Gestión para Albergues Transitorios

Sistema profesional para la gestión de albergues transitorios (telos) con funcionalidades específicas para el negocio.

### ✨ Características Principales

- 🔐 **Login seguro** para empleados (admin, supervisor, recepcionista)
- 🏠 **Gestión de habitaciones** con tipos (standard, premium, suite)
- ⏱️ **Control de turnos** por horas (2, 4, 6 horas)
- 💰 **Registro de pagos** (efectivo, tarjeta, transferencia)
- 🧹 **Sistema de limpieza** con tiempo de gracia
- 📊 **Métricas en tiempo real** (ocupación, ingresos, rotación)
- 🔔 **Notificaciones** via Socket.io
- 📈 **Reportes diarios** automatizados
- 🔒 **Privacidad total** - Sin datos de clientes
